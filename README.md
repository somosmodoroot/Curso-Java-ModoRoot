## 🚀 Sobre este Curso

Este repositorio contiene todo el material práctico, código fuente documentado, guías de instalación y diapositivas en PDF del **Curso de Java Profesional** de **Modo Root**. 

A diferencia de otros cursos que solo te enseñan la sintaxis básica, aquí entenderás **cómo funcionan las cosas bajo el capó**: la gestión de memoria física, la compilación de Bytecode, el comportamiento de la JVM y patrones de diseño empresariales que te servirán para toda tu carrera como ingeniero.
